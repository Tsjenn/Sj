# Newgrounds upload pack

newgrounds.com → sign up free → Create → Game → upload the zip →
paste the matching description + tags → submit for judgment.

WHICH ZIP MATTERS (product rules): the Full zips are PAID products —
never upload those free. SKYLINE is the one game the owner approved
as free-with-ads on portals, so it uses the portal build. The other
two go up as free DEMOS that link to the paid itch versions. All art
and music are ours, so the "must own all assets" rule is satisfied —
tick the ownership boxes honestly.

Viewport sizes: use the width/height the games declare in their
index.html (they're responsive; 960×600 is a safe frame for all
three).

## Judgment-phase notes

New uploads enter "Under Judgment" where the community votes. Two
honest levers: a clean icon/thumbnail (we have marketing/ art for all
three) and replying to early comments. Don't ask anyone to vote — the
community punishes it, and so do our own rules.
