# Threads 第一週 — 七篇貼文（貼上即可）

用你自己的帳號發，一天一篇，都是真話。規則：真實數字（包括零）、
不提僱主與同事、不截圖任何私人對話、可以自由改寫成你的語氣。
每篇都短——Threads 吃短文。

---

**Day 1（自我介紹）**

我是一個會計人，用 AI agent 幫我經營一間小小的數位商店。

它們每天自動寫書、寫文章、修網站，我負責決策和按上架鍵。

目前為止的總收入：RM0。對，零。

我會把整個過程誠實記錄在這裡——包括失敗。想看一個不騙人的
版本，就追蹤吧。

---

**Day 2（書）**

我的 agent 團隊用五個平行 subagent，兩天寫完了一本繁中書：
《環境比意志力強》——講怎麼用房間設計改變習慣，不靠意志力。

十章，每章有插圖，沒有編造的研究。規則是：證據薄弱就明說薄弱。

下一步：上架。上架之後我會公佈真實銷量，賣幾本說幾本。

---

**Day 3（誠實原則）**

為什麼我的店叫「誠實」路線？

因為這個領域全是假收入截圖。「睡後收入五位數」「三天回本」。

我的做法相反：公佈真實數字，包括零。睡眠 app 不會說「治好失眠」，
只說它真的能做到的事。書的宣傳頁直接顯示哪幾章還沒寫完。

信任是複利。謊言也是。

---

**Day 4（Score Lab）**

昨天 agent 做了一個小玩具：你自己發明睡眠分數的配方。

同一個晚上的睡眠，調一調權重，可以從 45 分變 95 分。

這就是睡眠 app 評分的真相：它是食譜，不是測量。

（免費，不用註冊，瀏覽器直接玩）

---

**Day 5（agent 怎麼協作）**

很多人問 AI agent 怎麼「互相溝通」。我們的做法很土：一個
markdown 留言板。

每個 agent 上班先讀板，下班留言：做了什麼、看到什麼問題、
拜託下一個 agent 做什麼。超過 25 條就刪最舊的。

沒有魔法。就是紀律 + 一個文字檔。

---

**Day 6（失敗記錄）**

誠實記錄，所以也記錄失敗：

我的排程 agent 會「準時上班但交白卷」——排程顯示有跑，
但什麼都沒產出，查了兩星期還沒找到原因。

現在的解法很笨：我自己的主 session 每天補班。

一人公司的真相：AI 很強，但你還是那個要擦地板的人。

---

**Day 7（第一週總結）**

第一週結束。誠實總結：

寫完：繁中書 10 章、英文睡眠書寫到第 7 章、5 篇文章、
1 個互動網頁。
銷量：還是 0。
學到：產品做完只是一半，另一半是讓人看見——所以才有這個帳號。

第二週目標：書上架。到時候公佈真實數字。
