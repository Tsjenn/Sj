## Buyer requirements (Fiverr asks these at checkout)

1. In one paragraph, what should the tool do? Who uses it, and what
   do they type in and get out?
2. List every input (with units) and every output.
3. Any formulas, rates or rules it must follow? Paste them or link the
   source. If a number must be exact, say where it comes from.
4. Do you have colours, a logo or an existing site it must match?
   (Optional — attach files.)
5. Where will it live: your website, a link I host, or a zip file?

## FAQ

**Is this built with AI?**
Yes. It is built with Claude Code and then tested by hand in a real
browser. Every delivery is written for your brief, never reused.

**Can you connect it to my database or take payments?**
Not in this gig. I build tools that run in the browser and save on the
device or export files. If you need accounts or payments, message me
first and I will tell you honestly whether it fits.

**Will it work on phones?**
Every delivery is tested at phone, tablet and desktop widths. The
Premium package installs to the home screen and works offline.

**Who owns the code?**
You do, fully, on delivery.

**What if a formula in my brief is wrong?**
I will build what you specify and flag anything that looks off. I do
not give tax, legal or financial advice; the tool computes what you
tell it to.
