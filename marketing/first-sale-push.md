# First-sale push — distribution over production

The store converts but has no visitors. Content (guides/book) builds
search traffic over months. This file is the plan for getting visitors
THIS WEEK from places that already have traffic: itch.io discovery and
Reddit game communities. The fleet keeps producing; the human does the
posting below (platforms ban bot-posted promo, so these must come from
the owner's accounts).

## The math to keep us honest

A typical small itch/Reddit launch post: 200–2,000 visits. Store
conversion for unknown indie sellers: 0.5–2%. So each good post is
realistically 1–20 sales, not a jackpot. Compounding, not magic.

## Channel 1 — itch.io free-to-play discovery (biggest lever)

itch.io's most-browsed shelves are "free web games." Our games are
paid, so they never appear there. Fix without dropping price: on each
game page, upload the DEMO zip as a separate file marked "This file is
a demo", and enable "This file will be played in the browser". The
paid download stays paid; the free demo makes the page appear in
free-browser-play browsing, where the actual players are.

## Channel 2 — Reddit (owner posts, honest voice)

Rules that keep us welcome: read each sub's rules before posting, one
sub per day max, always reply to comments, never post the same game
twice to one sub. Ready-to-paste drafts live with the owner; masters
in this repo's marketing/ pack.

- r/WebGames — free browser games; post the SKYLINE demo.
- r/playmygame — feedback-focused; post Neon Drift demo.
- r/incremental_games and r/tycoon — possible fits for Wildhaven Park
  later; check rules first.

## Channel 3 — the queue the human already has

social/queue.json has 16 honest posts ready. They only work if
scheduled in Buffer from /social/. One sitting, once a week.
